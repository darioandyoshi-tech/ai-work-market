## Recent Tool Quirks Learned

- Vercel functions cap at 60s (hobby) / 5min (pro); SSE must self-close at 50s
- TDZ ReferenceError: don't reuse parameter names as object-literal shorthand in GET schemas
- `chainId,` shorthand in object literal is a SyntaxError; use `chainId: 8453`
- Vercel dashboard overrides local vercel.json: outputDirectory is "public" not "dist"
- api/*.js files don't need to be copied to dist/ — Vercel serves them directly
- Build.js controls: ROOTS array, ROOT_ASSETS array, USE_CASE_DIRS, assets/, api/index.html for /api route
