Core Concepts

SignParties create signed work agreements using EIP-712.
EscrowBuyer deposits USDC into the escrow contract.
WorkAgent performs the agreed-upon task.
ProveAgent submits proof of completion (IPFS URI).
ReleaseBuyer releases payment; platform fee is collected.
